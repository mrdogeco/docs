## Usage

```tsx
import { LiveIndicator } from "@/components/live-indicator"

<LiveIndicator status="live" elapsed="63'" />
```

<Callout title="Only three states">
  This component models exactly three states because that's all the
  underlying match-status data reliably distinguishes. Don't add a
  "postponed" or "delayed" variant without a data source that can actually
  back it — see the note in the component source.
</Callout>
