## Use with the Mr. Doge SDK

The real `PickResult` type (from `ai.recommendations`) is
`"won" | "lost" | "push" | null` — a direct passthrough, no adapter
function needed. Only render this component once a pick has actually
settled (`result` isn't `null`):

```tsx
import type { Recommendation } from "@mrdoge/protocol"
import { SettlementBadge } from "@/components/settlement-badge"

function SettledPick({ recommendation }: { recommendation: Recommendation }) {
  if (!recommendation.settled || !recommendation.result) return null
  return <SettlementBadge result={recommendation.result} />
}
```
