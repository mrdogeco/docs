## Usage

```tsx
import { OddsSelector } from "@/components/odds-selector"

<OddsSelector
  label="Match Result"
  options={[
    { id: "home", label: "PSG", price: "2.50" },
    { id: "draw", label: "Draw", price: "3.35" },
    { id: "away", label: "Arsenal", price: "3.10" },
  ]}
  selectedId={selectedId}
  onSelect={setSelectedId}
/>
```

## useOddsMovement

`movement` isn't something you'd normally compute by hand — pair
[useLiveOdds](/docs/ui/hooks/use-live-odds) with
[useOddsMovement](/docs/ui/hooks/use-odds-movement) to derive it from real
price changes as they happen:

```tsx
const market = useLiveOdds({ matchId, betTypes: ["SOCCER_MATCH_RESULT"] })
const movementById = useOddsMovement(market)
// movementById[item.id] is "up" | "down" | undefined
```
