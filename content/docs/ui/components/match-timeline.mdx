## Usage

```tsx
import { MatchTimeline } from "@/components/match-timeline"

<MatchTimeline
  entries={[
    { id: "1", side: "match", type: "divider", live: true, description: "2nd Half 1 - 0" },
    { id: "2", side: "match", type: "divider", description: "HT 1 - 0" },
    { id: "3", time: "39'", type: "yellow-card", side: "away", description: "J. Mickels" },
    { id: "4", time: "31'", type: "goal", side: "home", description: "J. Bogere", score: { home: 1, away: 0 } },
  ]}
/>
```

`type` is an open string — pass whatever event kinds your data has (e.g.
`"goal"`, `"yellow-card"`); unrecognized ones fall back to a generic
marker instead of being rejected. `side: "match"` entries render as a
divider (a horizontal line either side of centered text) instead of a
row — pass `live` to color the current one red instead of muted.

## Use with the Mr. Doge SDK

Match Timeline takes a plain `entries` array, so it works with any data
source. See the
[Match Timeline Adapter](/docs/ui/adapters/mrdoge-sdk#match-timeline) for
the real function mapping a match's timeline (from
`matches.get()`/`matches.subscribe()`) onto this prop — the one behind
the example above. It filters down to goals, cards, penalties, and
half/full-time — the rest of a real timeline (fouls, tackles, throw-ins,
corners, goal kicks, offsides, shots) stays available on the match object
itself if you want a denser view.
