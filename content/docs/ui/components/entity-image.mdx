## Usage

```tsx
import { EntityImage } from "@/components/entity-image"

<EntityImage src="https://api.mrdoge.co/images/teams/1.png" name="Palmeiras" />
```

When `src` is missing or fails to load, it falls back to the entity's
initials — shown above, since these demo entities have no real logo URL.

## Use with the Mr. Doge SDK

Team and region logos are served from a stable public CDN — no SDK call,
no auth, just the entity's `id`:

```ts
export function teamLogo(id: number) {
  return `https://api.mrdoge.co/images/teams/${id}.png`
}

export function regionFlag(id: number) {
  return `https://api.mrdoge.co/images/regions/${id}.png`
}
```

See [Images](/docs/reference/images) for the full CDN reference (caching,
response codes).
