## Usage

```tsx
import { RegionAccordion } from "@/components/region-accordion"

<RegionAccordion
  regions={[
    {
      id: "1",
      name: "Brazil",
      eventCount: 12,
      competitions: [
        { id: "1", name: "Brasileirão Série A", eventCount: 8 },
        { id: "2", name: "Brasileirão Série B", eventCount: 4 },
      ],
    },
  ]}
  onSelectCompetition={(regionId, competitionId) => console.log(regionId, competitionId)}
/>
```

This is a navigation/discovery building block — region and competition
selection, not a match list. Compose it with
[Event Card](/docs/ui/components/event-card) or
[Odds Board](/docs/ui/components/odds-board) once you have a
`competitionId` to fetch matches for.

## Use with the Mr. Doge SDK

`Region.competitionIds` only gives IDs, not full `Competition` objects —
this adapter takes both `regions.list()` and `competitions.list()`
responses and groups the latter by `regionId`:

```tsx
import type { Region, Competition } from "@mrdoge/protocol"
import type { RegionAccordionProps } from "@/components/region-accordion"

function regionsToProps(
  regions: Region[],
  competitions: Competition[],
): RegionAccordionProps {
  return {
    regions: regions.map((region) => ({
      id: String(region.id),
      name: region.name,
      eventCount: region.eventCount,
      competitions: competitions
        .filter((competition) => competition.regionId === region.id)
        .map((competition) => ({
          id: String(competition.id),
          name: competition.name,
          eventCount: competition.eventCount,
        })),
    })),
  }
}
```
