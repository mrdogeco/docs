Pairs with [useLiveMatch](/docs/ui/hooks/use-live-match) — this is the same
live connection powering the "With odds" example on
[Match Card](/docs/ui/components/match-card). `odds.subscribe` is
Business tier: on a lower tier the subscribe call rejects, the hook resolves
to `null`, and the caller just doesn't render an odds row — no fallback.

## Installation

<InstallTabs name="use-live-odds" />

Same three supporting files as [useLiveMatch](/docs/ui/hooks/use-live-match)
(the SDK client singleton and the token route) — if you've already installed
that hook, you likely have them.

## Usage

```tsx
import { useLiveMatch } from "@/hooks/use-live-match"
import { useLiveOdds } from "@/hooks/use-live-odds"

function Match({ matchId }: { matchId: string }) {
  const match = useLiveMatch({ matchId })
  const markets = useLiveOdds({
    matchId: match?.id,
    betTypes: ["SOCCER_MATCH_RESULT", "SOCCER_MATCH_RESULT_PRELIVE"],
  })
  const market = markets?.[0]

  // markets is undefined while loading, null if unavailable
  // (wrong tier, or no live market on this match right now)
}
```

Takes a single options object, like every real SDK method it wraps
(`odds.subscribe(params)`) — not positional arguments.

A `betTypes` filter that only ever matches one market (like
`SOCCER_MATCH_RESULT` above) makes indexing `markets?.[0]` safe. Some bet
types post one market *per line* instead — see
[Odds Selector's "Multiple Lines" example](/docs/ui/components/odds-selector#multiple-lines)
for `SOCCER_UNDER_OVER`, which returns a separate market for every
Over/Under threshold.

Some markets also use a different sysname before kickoff — the standard 1X2
line above is `SOCCER_MATCH_RESULT_PRELIVE` up until the match goes live,
then `SOCCER_MATCH_RESULT`. A given match only ever has one of the two at
a time, so filtering on both gets the market regardless of match state.

## Returns

`Market[] | null | undefined` — `undefined` while loading or when `matchId`
is `undefined`, `null` once loaded if no markets matched (wrong tier, or
none live right now), otherwise every matching market, updated in place as
`odds.upd` events arrive.
