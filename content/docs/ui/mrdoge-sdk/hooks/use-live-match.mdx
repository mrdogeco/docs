Wraps `matches.subscribe()`. Pushes score, status, and clock updates in
place as `stats.upd` / `status.upd` events arrive, for as long as the
component stays mounted.

## Installation

<InstallTabs name="use-live-match" />

Installing this pulls in three files: the hook itself, a browser SDK client
singleton (`getMrDogeClient`), and a Next.js route at
`app/api/mrdoge/token/route.ts` that mints short-lived tokens using
`@mrdoge/node` and your own `MRDOGE_ODDS_API_KEY` — the browser client never
sees the raw key.

## Usage

```tsx
import { useLiveMatch } from "@/hooks/use-live-match"

const match = useLiveMatch({ matchId })
```

Takes a single options object, like every real SDK method it wraps
(`matches.subscribe(params)`) — not positional arguments.

## Parameters

## Returns

`MatchDetail | null | undefined` — `undefined` while loading (or while
`matchId` is `undefined`), `null` if the subscribe failed (no fallback data
— an honest empty state beats a fake one), otherwise the current snapshot,
updated in place as `stats.upd` / `status.upd` events arrive. Feed it into
[`matchToMatchCardProps`](/docs/ui/mrdoge-sdk/usage#match-card) or
[`matchToMatchHighlightProps`](/docs/ui/mrdoge-sdk/usage#match-highlight)
for component props.
