mrdoge-ui is a set of React components for building sports betting
interfaces: event cards, odds selectors, bet slips, match timelines, and
related building blocks. Components are distributed as source code through
a shadcn/ui-compatible registry, not as an installable package. There is no
dependency on any particular data provider — every component takes plain
props.

## Installation

Works in any project with Tailwind CSS and the shadcn/ui CLI configured.
Install a component with:

<Tabs items={["pnpm", "npm", "yarn", "bun"]}>
  <Tab value="pnpm">
    ```bash
    pnpm dlx shadcn@latest add https://mrdoge.co/r/event-card.json
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx shadcn@latest add https://mrdoge.co/r/event-card.json
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx shadcn@latest add https://mrdoge.co/r/event-card.json
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx shadcn@latest add https://mrdoge.co/r/event-card.json
    ```
  </Tab>
</Tabs>

This copies the component and its dependencies into your project under
`components/`. You own the resulting code and can modify it freely.

## Components

Event Card, Odds Selector, Live Indicator, Bet Slip, Match Timeline, Team
Form Indicator, and Competition Header. See [Components](/docs/components)
for a live preview, props, and the install command for each.

## Use with the Mr. Doge SDK

mrdoge-ui components accept plain props, so they work with any data
source. They pair directly with
[`@mrdoge/client`](https://mrdoge.ai), which provides typed, real-time
sports data over HTTP and WebSocket:

```tsx
import { MrDoge } from "@mrdoge/client"
import { EventCard } from "@/components/event-card"

const mrdoge = new MrDoge({ authEndpoint: "/api/mrdoge/token" })

const match = await mrdoge.matches.get({ id: matchId })
const [market] = await mrdoge.odds.list({ matchId })

// mrdoge-ui uses generic status labels so it has no dependency on the
// SDK's vocabulary — map the SDK's three states to the component's three.
const status = { upcoming: "scheduled", live: "live", completed: "finished" }[
  match.status
]

<EventCard
  competition={match.competition.name}
  status={status}
  kickoff={match.startTime}
  home={{ name: match.homeTeam.name }}
  away={{ name: match.awayTeam.name }}
  odds={market.betItems.map((item) => ({
    id: item.id,
    label: item.code,
    price: item.price.toFixed(2),
    suspended: !item.isAvailable,
  }))}
/>
```
