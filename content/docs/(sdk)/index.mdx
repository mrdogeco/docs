The Mr. Doge SDK powers the Mr. Doge app — live odds across every major
sport, AI picks with reasoning attached, and market data you can build
on. These docs walk you through installation, authentication, and every
method the SDK exposes.

  </Tab>

  </Tab>
  <Tab value="yarn">
```bash
yarn add @mrdoge/node
```
  </Tab>
  <Tab value="bun">
```bash
bun add @mrdoge/node
```
  </Tab>
</Tabs>

```ts title="index.ts"
import { MrDoge } from "@mrdoge/node";

const mrdoge = new MrDoge({
  apiKey: process.env.MRDOGE_API_KEY!,
});

const { data } = await mrdoge.matches.list({
  sports: ["soccer"],
  status: ["live"],
  limit: 10,
});

console.log(data);
```
