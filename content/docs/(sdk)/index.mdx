The Mr. Doge SDK powers the Mr. Doge app — live odds across every major
sport, AI picks with reasoning attached, and market data you can build
on. These docs walk you through installation, authentication, and every
method the SDK exposes.

## 30-second taste

Pick your runtime — Node, Next.js, or any edge runtime. Same SDK, same data.

<Tabs items={["Node", "Next.js", "Edge"]}>
  <Tab value="Node">
```ts
import { MrDoge } from "@mrdoge/node";

const mrdoge = new MrDoge({
  apiKey: process.env.MRDOGE_API_KEY!,
});

// stream live matches
const sub = await mrdoge.matches.subscribeLive({
  sports: ["soccer"],
});

sub.on("match.upd", (match) => {
  // live scores, corners, cards, etc.
  console.log(match.stats);
});

// or pull today's AI picks
const { data } = await mrdoge.ai.recommendations.list({
  limit: 10,
  minOdds: 1.5,
});
```
  </Tab>
  <Tab value="Next.js">
```ts title="app/api/recommendations/route.ts"
import { MrDoge } from "@mrdoge/node";

const mrdoge = new MrDoge({
  apiKey: process.env.MRDOGE_API_KEY!,
});

export async function GET() {
  const { data } = await mrdoge.ai.recommendations.list({
    minEdge: 0.05,
    confidence: "High",
    limit: 10,
  });

  return Response.json(data);
}
```
  </Tab>
  <Tab value="Edge">
```ts
// Cloudflare Workers / Vercel Edge / Lambda
import { createHttpClient } from "@mrdoge/http";

export default {
  async fetch(req, env) {
    const mrdoge = createHttpClient({
      apiKey: env.MRDOGE_API_KEY,
    });

    const matches = await mrdoge.call("matches.trending", { limit: 5 });
    return Response.json(matches);
  },
};
```
